📚 Comprendre les Prix de Transfert

Qu'est-ce qu'un prix de transfert ?

Les prix de transfert sont les prix auxquels les entités liées (filiales, succursales, etc.) d'une même entreprise multinationale échangent des biens, services ou propriété intellectuelle. Ces prix sont cruciaux pour la conformité fiscale et la gestion comptable.
Pourquoi c'est important ?

✓ Conformité Fiscale : Respecter les règles OCDE et nationales
✓ Optimisation Fiscale : Maximiser les bénéfices légalement
✓ Documentation : Justifier vos prix en cas d'audit
✓ Risques Réduits : Éviter les pénalités et ajustements fiscaux
Formule Principale (Cost Plus) :
Prix de Transfert = Coût + (Coût × Marge %)
Exemple : 1000€ + (1000€ × 15%) = 1150€
Les 3 Principales Méthodes :

1. Cost Plus (Coût Plus)
Ajoute une marge au coût total. Idéale pour les services et biens standards.

2. Resale Price (Prix Revente)
Réduit le prix de revente d'une marge. Utilisée pour les biens revendus.

3. Profit Split (Partage des Bénéfices)
Divise les bénéfices selon les contributions. Pour les actifs hautement intangibles.
Entités Liées : Sociétés ayant une relation de contrôle ou d'influence directe
Arm's Length Principle : Prix que demanderaient des entreprises indépendantes
Bénéfice Économique : Avantage obtenu par une entreprise liée
Documentation TP : Preuves justifiant les prix de transfert utilisés
